阅读、理解与留下想法

13 个段落 · 约 6 分钟

阅读不只是获取信息，也是把新的内容与已有经验联系起来。一个好的阅读器，应当让人能够专注于文字，在需要时获得解释，并留下自己的思考。

一、Markdown 的阅读体验

Markdown 用简单的标记表达重要观点、强调、倾斜、 行内代码、已删除的内容与参考链接。阅读时，这些标记应当成为清晰的排版，而不是需要读者自行脑补的符号。

  • 清晰的标题与目录
  • 舒服的正文宽度和行距
  • 可以回到原文的笔记

读到值得停下来的地方，就在原文旁留下一句话。批注不是读后感，它锚定在某一段上。

代码与引用

行内代码用 rgb(var(--bg)) 这样的写法引用主题变量；整段代码则保留缩进：

// 主题变量由 <html data-theme> 决定
export function resolveTheme(theme) {
  if (theme === "system") {
    return window.matchMedia("(prefers-color-scheme: dark)").matches
      ? "dark"
      : "light";
  }
  return theme;
}

二、让 AI 帮助理解

遇到陌生概念时，选中文字并询问：它是什么意思？它与前文有什么关系？有没有更容易理解的例子？

  1. 选中正文中的一句话
  2. 选择「解释」或「提问」
  3. 回答留在右侧，与原文一一对应
操作结果位置
解释一段话的释义右侧笔记栏
提问带原文引用的回答右侧笔记栏
划线原文上的标记正文行内

注：解析层目前只有 heading / paragraph / listItem / code / quote 五种块类型，没有表格。上表只用于观察配色，不代表现有能力。
