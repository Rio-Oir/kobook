# Assets

Everything under `public/` is part of this repository's own work and is released
under the same MPL-2.0 terms as the rest of the project (see `LICENSE`).

- `public/covers/01.webp` … `12.webp` — illustrations drawn for this project.
  They are decorative defaults for articles without a cover image.
- `public/icon-192.png`, `public/icon-512.png`,
  `public/icon-512-maskable.png`, `public/apple-touch-icon.png` and
  `public/favicon.svg` — the project's marks.
- No third-party fonts, stock photography, icon sets or textures are bundled.
  The interface uses system fonts and inline SVG.
